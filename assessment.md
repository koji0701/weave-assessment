# Engineering Impact Dashboard Assignment

# Overview

Welcome! At Weave, we help engineering teams understand their productivity and impact. For this assignment, you'll analyze real GitHub data to identify impactful engineers.

# The Task

[PostHog](https://posthog.com/) is a popular open-source company. Using the [PostHog GitHub repository](https://github.com/PostHog/posthog), create an  analysis and dashboard that identifies the most impactful engineers. 

The expected audience is a busy engineering leader on the PostHog team. Assume they understand the basics of what people do but they aren’t able to be in the weeds enough to read every line of code or PR description.

**Your job:**

1. Define what "impact" means for software engineers (there’s no one right answer!)
2. Gather relevant data from the PostHog repo
3. Analyze the data using your chosen metrics
4. Create an interactive dashboard showing the top 5 most impactful engineers
5. Host it somewhere we can view it

**Time limit:** 1 hour

**Tech stack:** Whatever you want
